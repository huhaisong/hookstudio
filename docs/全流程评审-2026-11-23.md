## 一、缺陷 bug（必须修复）

### B1. 预设接口全部 500（批4 回归）✅ 已修复（227b8dd）
- **场景**：设置页「导出预设/导入预设」，或任何对 `/api/config/preset` 的请求。
- **当时表现**：GET/PUT 全部 500 空 body，包括未登录应 401 的场景——鉴权调用写错
  （`auth.require` 不是 auth 模块的函数）。
- **影响**：批4 交付的 D5 功能整体不可用；且自测/烟测都没有覆盖这个新端点，所以漏网。
- **修复**：改 `auth.current_user`；复测 401/400/200 全部正确。附带修复：导入的
  `max_concurrent` 未夹紧（存 99 读 8 的怪状态）。
- **教训（待办）**：**新增端点必须进烟测**——smoke.py 加一条 `/api/config/preset` GET。

### B2. 项目名接受 Windows 非法字符，出片必炸
- **场景**：建项目时名称填 `测试<>|:*?`（API 实测 200 接受；前端无过滤无提示）。
- **当前表现**：项目正常创建，名字原样入库。
- **问题影响**：单片出片文件名 = `项目名_时长_时间.mp4`（render.run 拼接）——名字里带
  `<>|:*?` 时成片写盘必然失败，而且用户不知道是名字的问题。文件夹名做项目名时
  （「留空则用文件夹名」）同样可能带入。
- **修改方案**：`core.create` 入口过滤（非法字符换 `_`）+ 前端提交前提示；
  已存在的脏名字在出片前预检并报人话。

### B3. 转写产出 0 台词时无任何警告
- **场景**：素材无人声/纯音乐，转写完成。
- **当前表现**：3 集全部「已完成」，集状态 done 但 0 句台词，界面无提示；
  whisper 还把 initial_prompt（「请用简体中文转写。」）当台词写进去。
- **问题影响**：用户以为正常完成，到第 3 步编排必然失败，自己排查半天。
- **修改方案**：转写收尾统计每集行数，0 行的集在步骤 1 面板标黄
  （「这一集没识别出台词——素材可能没有人声」）；项目摘要加同类提示。

### B4. 短素材剧（每集 < 40 秒）编排必然全废，且报错不解释
- **场景**：每集 30 秒的素材建项目、跑编排（AI 与本地兜底都一样）。
- **当前表现**：「AI 给出的结构都不可用（时长不足或编号越界），请重试」——
  实际根因是 `BLOCK_MIN=40` 硬下限：30 秒的块 `_lift_blocks` 延不到 40 秒整块丢弃，
  AI 套和本地兜底套全部被筛空（评审实测，含 B5 兜底路径）。
- **问题影响**：短素材用户永远编不出来，错误信息只让"重试"，重试多少次都一样。
- **修改方案**：`BLOCK_MIN` 随素材自适应（`min(40, 集长×0.6)`），或在失败信息里
  明确说「每集素材只有 30 秒，低于单块 40 秒下限——请用更长的剧集，或把每套
  时长调到 0.5 分钟以内」。

### B5. 「查看/修改台词」弹窗底部按钮初始在视口外
- **场景**：720p 高度视口打开弹窗。
- **当前表现**：弹窗内容高约 760px，保存/放弃按钮在 y≈731-757——视口底边裁切，
  打开时看不见也不可点（需自行滚动弹窗才能发现按钮）；评审中第一时间全部点空。
- **问题影响**：用户改完台词找不到「保存」在哪，第一次使用极易卡住。
- **修改方案**：弹窗加 `max-height: calc(100vh - 80px)` + body `overflow:auto`，
  或把「保存/放弃」固定在弹窗底部安全区。

## 二、体验痛点（建议优化）

### P1. 文件树选目录在深路径下极难用
- **场景**：建项目选素材文件夹（评审在 D 盘 7 层深目录实测）。
- **当前表现**：无路径输入框、无搜索；滚动位置**跨刷新持久化**（重开页面直接停在
  `D:\$RECYCLE.BIN`）；键盘滚动不可靠；盘符按钮在子目录态点击无响应。
- **影响**：素材在深目录的用户每次建项目都要一层层点+对抗滚动状态。
- **方案**：给建项目浏览器加「粘贴路径」输入框（或 pickmem 的「最近用过」快捷项——
  direct 出片已有，补齐到建项目）；滚动位置改会话内记忆，重开回根。

### P2. 无目录选中时点「扫描并创建」完全无反馈
- **场景**：刚打开页面直接点「扫描并创建」。
- **当前表现**：静默（无 toast、无红框）。
- **影响**：用户不知道要先选目录。
- **方案**：toast「先在下面选一个放着剧集的文件夹」。

### P3. AI 编排失败信息缺场景化建议
- **场景**：小素材编排失败（评审实测）。
- **当前表现**：「AI 给出的结构都不可用（时长不足或编号越界），请重试」——没有告诉
  用户素材太短这个根因，"重试"无法自救。
- **方案**：失败分类带建议：素材总时长 < 套数×下限时提示「素材只有 X 分钟，
  建议把每套时长调到 Y 分钟以内」（预算预警已有数据，接到失败信息里即可）。

### P4. 登录页空输入提交无反馈
- **场景**：用户名/密码留空直接点登录。
- **当前表现**：静默（错误密码有红字提示，空输入反而没有）。
- **方案**：与错误密码同款红字「请输入用户名和密码」。

### P5. 导出预设成功无 toast
- **场景**：设置页点「导出预设」。
- **当前表现**：静默下载（浏览器下载条在 IAB 里还看不见）。
- **方案**：toast「预设已导出到下载目录」。

### P6. 台词弹窗切集时未保存修改无保护（待复核）
- **场景**：编辑台词后直接点另一集 tab。
- **当前表现**：评审因坐标偏移未能完整复现切换；若切集直接丢弃未保存内容且无提示，
  用户手改的台词会静默丢失。
- **方案**：dirty 状态切集时 askConfirm「这一集还没保存，丢弃修改并切换？」

## 四、验证为正常的（实测通过，保持不动)

- 登录：错误密码红字提示清晰、加载态（按钮禁用+「登录中…」）正常
- 全局顶部进度条 + 右上「中止」：抹字幕/AI 编排都有，进度带卷号/集名/秒数/百分比
- 确认弹层（askConfirm）：「生成剪辑结构」确认单（模型/套数/**今日次数消耗**/预计耗时/
  重复度口径）与「删除项目」确认单（删什么/不会删什么/后果三分段+红色危险按钮）质量都很高
- 抹字幕：完成后按钮组出现「预览第一集/打开文件夹」，幂等提示
  （「设置没变时再点生成只会补没做过的集；改过台词后不用重做底片」）文案极佳
- AI 预算预警：改参数实时重算（200% 超限 → 「素材够分」），不拦截只提示，口径与文档一致
- 台词编辑器：格式说明/保存提示（「之前生成的结构和分镜要用新台词，请重新生成」）清晰
- 设置页：新控件（音频适配/编码停滞熔断）+ 磁盘余量提示 + 当前编码提示全部就位
- 预设接口修复后：未登录 401 / 版本错 400 / 白名单外键忽略 / 类型收敛 / stall_sec
  越界 400 / 合法导入生效
- 删除项目：任务取消→墓碑→等待→清残留，返回 still_running 供前端判断（设计合理）
