# 域名与备案指南

写给需要给「钩子工坊」办上线手续的人。按顺序执行即可，不需要懂技术。

---

## 零、先看结论：你可能不需要备案

「体验额度」这部分只需要一台服务器跑 Key 代理，**代码里没有网页给人看**。这种情况下：

| | 香港/新加坡服务器 | 国内服务器 + ICP 备案 |
|---|---|---|
| 能否立即上线 | **当天** | 3–22 个工作日 |
| 费用 | 约 25–35 元/月 | 约 100–200 元/年 + 域名 50 元/年 |
| 国内访问延迟 | 30–80ms | 5–30ms |
| 是否需要 ICP | 不需要（服务器在境外） | 必须 |
| 合规风险 | 服务境内用户严格说仍属灰区，被举报可能要求整改 | 无 |

Key 代理每次只转发几 KB 的 JSON，**30–80ms 的延迟完全感觉不到**。

**建议路径**：
1. 先买香港轻量服务器，当天把体验额度跑起来，验证有没有人真的用
2. 确认有人用了，再回头补国内服务器 + 备案（也可以一直用香港，因为你不做面向公众的网站）

如果你打算做一个**给用户看的产品官网/下载页**（有网页界面），那就必须走国内 + 备案，或者官网放香港。

下面两种路都写了。

## 一、域名怎么选

### 1. 在哪买（关键）

**必须在国内注册商买，否则不能直接备案**：

- 阿里云万网：wanwang.aliyun.com
- 腾讯云 DNSPod：dnspod.cloud.tencent.com

在 GoDaddy、Namecheap、Cloudflare 买的域名要「转入」国内注册商才能备案，多花 3–7 天。**别图便宜去国外买**。

### 2. 后缀怎么挑

| 后缀 | 首年 | 续费/年 | 说明 |
|---|---|---|---|
| `.com` | 30–60 元 | 75–90 元 | 最稳，用户信任度最高，好名字基本被占 |
| `.cn` | 20–30 元 | 35–40 元 | 便宜、国内认可，需实名认证，个人可注册 |
| `.top` `.xyz` | 5–15 元 | 25–40 元 | 便宜但显得不专业，容易被当垃圾站 |

**推荐 `.com`，抢不到再退 `.cn`。**

### 3. 名字怎么起

- 短、能拼读、不用连字符（`hook-studio` 这种最难口播）
- 拼音也别太长，超过 12 个字母就不好记
- 备选思路：
  - 英文组合：`hookstudio` `hooklab` `gouzilab`
  - 全拼：`gouzishop` `gouzistudio`
  - 短拼音 + 行业：`gouzi.video`（.video 后缀贵，慎选）
- 先查 `hookstudio.com` 是否可用，被占就换 `hookstudio.cn` → `hookstudiolab.com` 依次往下试

### 4. 买完立刻做的一步

**域名实名认证**（个人：身份证正反面）。不实名无法解析、无法备案。

- 阿里云：控制台 → 域名 → 信息模板 → 创建模板 → 上传身份证
- 审核：10 分钟 到 1 个工作日
- 认证通过后状态变「已实名」

## 二、服务器怎么买（要备案才需要看这节）

备案的前提是**你有一台中国大陆的服务器**，而且满足：

- 地域在中国大陆（华北/华东/华南任一）
- **包年包月，且时长 ≥ 3 个月**（按量付费的不能备案）
- 有公网 IP

推荐配置（只跑 Key 代理）：

| 项目 | 选择 |
|---|---|
| 产品 | 轻量应用服务器（比 ECS 便宜且够用） |
| 配置 | 2 核 2G，40G 系统盘 |
| 带宽 | 3–5 Mbps 峰值足够 |
| 系统 | Ubuntu 22.04 |
| 时长 | 先买 1 年 |

价格：新用户活动价约 100–200 元/年。阿里云、腾讯云都有。

**买完记得申请「备案服务码」**：一个实例可申请 5 个，每个只能用一次。

## 三、备案在哪提交

**唯一入口是云厂商的代备案系统，不是工信部网站。**

| 厂商 | 地址 |
|---|---|
| 阿里云 | beian.aliyun.com |
| 腾讯云 | console.cloud.tencent.com/beian |

个人不能自己去工信部提交，必须通过服务器提供商。

### 完整流程（以阿里云为例）

**第 1 步：准备（1–2 天）**
- [ ] 阿里云账号已注册 + 已完成个人实名认证
- [ ] 域名已买 + 已实名
- [ ] 服务器已买（≥3 个月，大陆地域）
- [ ] 已申请备案服务码

**第 2 步：填订单（30 分钟）**

登录 beian.aliyun.com → 点「开始备案」→ 按提示填三类信息：

1. **主体信息**：姓名、身份证号、证件住所、通信地址、手机号、邮箱
   - 手机号必须是**本人实名**的，管局会打电话回访，必须能接
   - 通信地址要详细到门牌号，没有门牌号写「XX 路 XX 号（已为最详细地址）」

2. **网站信息**：
   - 网站名称（见下方「命名禁忌」）
   - 域名
   - 网站内容：选「其他」或「个人技术分享」，备注写「个人技术学习与工具使用分享」
   - 服务器：选你刚买的那台实例

3. **上传材料**：身份证正反面 + 手机 App 人脸核验

**第 3 步：阿里云初审（1–2 个工作日）**

**第 4 步：工信部短信核验（5 分钟内收到短信，24 小时内必须完成）**
- 短信来自 12381，点链接完成核验，**超时作废，整个流程重来**

**第 5 步：管局审核（3–20 个工作日，多数省份 3–7 天）**
- 期间可能接到管局电话，问「你这个网站是做什么的」，照实说是个人学习使用

**第 6 步：拿到备案号，网站底部标注**
```
京ICP备2026XXXXXX号-1
```

**第 7 步：公安联网备案（开通后 30 天内）**
- 网址：beian.mps.gov.cn
- 需要：备案号、身份证、域名证书、网站负责人信息
- 审核约 3–7 个工作日，通过后拿到公安备案号，也要标在页脚

## 四、需要准备的材料清单

个人备案（大部分情况）：

- [ ] 身份证原件（拍照，四角完整、无反光、字迹清晰）
- [ ] 本人实名手机号 1 个（能接电话）
- [ ] 应急联系人手机号 1 个
- [ ] 常用邮箱
- [ ] 域名（已实名认证）
- [ ] 服务器备案服务码
- [ ] 人脸核验（手机装对应云厂商 App）
- [ ] 详细的通信地址

企业备案额外需要：

- [ ] 营业执照
- [ ] 法定代表人身份证
- [ ] 法定代表人手机号
- [ ] 网站负责人身份证（如非法人本人）

## 五、网站名称的坑（个人备案最容易卡在这）

个人备案的网站名审核很严，以下规则必须满足：

| 规则 | 说明 |
|---|---|
| ≥ 3 个汉字 | 「钩子工坊」4 个字，够 |
| 不能纯数字/纯字母 | 不行 |
| 不能含特殊符号 | 不行 |
| 不能以「中国/中华/中央/人民/国家」开头 | 不行 |
| 不能用域名本身命名 | 不行 |
| 不能含敏感词 | 反腐、赌博、医疗等 |
| **不能涉及行业或企业内容** | ⚠️ 这条最要命 |

**⚠️ 重点提醒**：「钩子工坊」里的「工坊」有可能被判定为经营性/行业内容，如果网站内容是「软件下载」，个人备案**大概率驳回**。

三种应对：

1. **最省事**：备案一个纯介绍页（写「个人剪辑技术笔记」），安装包不放服务器、走网盘分发。网站名写「钩子剪辑笔记」这类中性名
2. **最正规**：去办个体工商户（现在线上可办，1–3 天，免费），做企业备案，随便写
3. **最干脆**：只用香港服务器跑 API，不做官网，不备案

## 六、常见驳回原因（提前避坑）

| 驳回原因 | 怎么解决 |
|---|---|
| 证件照片不清晰 / 缺角 | 重拍，四角完整，别用截图 |
| 网站名称不合格 | 按上面第五节改 |
| 电话号段不对 / 打不通 | 用备案省份本地的实名号，保持畅通 |
| 网站已能访问 | **备案期间绝对不要开 80/443 端口对外**，否则直接被驳 |
| 域名未实名 / 未入库 | 等域名实名通过再提交；非阿里云域名要等 2–3 天入库 |
| 备案订单超 45 天未完成 | 重新提交 |

## 八、我的建议

**别等备案。** 备案 3–22 个工作日是纯等待，你在这个时间里什么也做不了。

今天就走这条最短路径：

1. 买域名（`.com` 优先），立刻实名
2. 买一台香港轻量服务器（2 核 2G，25–35 元/月）
3. 告诉我域名和服务器 IP，我把 Key 代理部署上去
4. **当天就能发给第一批人试用**

等有人用了、你确定要继续投入，再回头买国内服务器、办备案、甚至办个体户。那时候你已经有真实用户数据，知道这个投入值不值。
