# 去重改造（2026-11-17）：段级定位 / 复用台账 / 帧数预算

> 竞品源码剖析见 `_竞品分析/去重剖析与借鉴-复核-2026-11-17.md`。
> 本文只记**本次改了什么、为什么、怎么验、哪些数还没标定**。

## 1. 一句话

把「去重」从「画面扰动参数」升级成**可度量、可治理**的三件事：
出片前知道哪些素材用滥了（台账），出片时时间轴一位不差（帧预算 + 连续音轨），
发布前能说清楚跟哪条撞了哪几秒（段级定位）。

| # | 位置 | 改动 |
|---|---|---|
| A | `app/audiofp.py` | 新增 `locate_files()` 段级定位；指纹格式升级 v2（base64 头带 stride）；旧指纹兼容 |

| C | `app/render.py` + `app/batch.py` | 逐段微变速（帧数守恒）+ `_cut` 精确帧/纯视频分段 + 独立连续音轨 |
| D | `app/render.py` | `fp_grade()` 增加逐段质感微抖（±10%，只抖用户开着的项） |

### A. 段级定位为什么另起一套

存下来的 32bit 指纹是**符号位**（频带能量相对上一帧/全片均值升还是降）：

- 对重编码、重采样极敏感——实测同一条音频转一次码只剩 **0.77~0.84**（低于 `MIN_SIM 0.85`）；
- 长片按 `MAX_FRAMES` 抽帧后，复用段起点只要不是步长整数倍，两串采样点整体错开一两帧，逐窗比对**全部对不上**（实测 ratio=0）。

所以定位改成**按需读文件**，用 16 频带对数能量的「形状向量」（每帧去均值 + L2 归一）算余弦：

- 同源重编码 **0.83~1.0**；不同内容 **~0.2**；分离度足够；
- 只在「整片相似度 ≥ `NEAR_SIM`」的候选对之间算，5 分钟片约 0.4s，不落盘、不进队列。

### B. 台账按「套」记，不按「计划」记

- 存储：`project.json` 的 `reuse.sets = { "代次:套号": [块键…] }`，次数读时现算；
- 块键：`集号:起-止`（0.1s 取整）；查不到精确键时按「同集、重叠过半」兜底（AI 重排会挪边界）；
- **出片成功才记**（`batch.render_plans`），计划阶段不记——AI 编排可能重跑/整套被弃；
- 同一套重渲覆盖同一条，不重复计数；
- 选段：`score × 1/(1+次数×0.6)` 降权；次数 ≥ `MAX_USE(3)` 的块第一轮不挑，独有素材不够才回用。

### C. 帧数预算与「音画漂移」的真根

三步约束：相邻限幅 → 总量归一 → 整数帧分配 → 反算速度。片长一位不差，每段至少 2 帧。

**顺带修掉一个老问题**：分段 mp4 自带 AAC 音轨，每段有约 30ms 编码器填充；
concat 按「文件时长」排段，填充按段累加——4 段多 0.12s，20 段差半秒，这就是
「越往后越不同步」的根。现在帧数路径下：

1. 分段**只出画面**（`-an`），文件时长 = 视频时长；
2. `_audio_track()` 按同一份计划重建一条 PCM 连续音轨（每段 `atempo` + `apad` + `atrim` 到精确 `out_dur`，片头卡补等长静音）；
3. 最后 mux 时只编一次 AAC（`loudnorm` 也在这一步）。

### D. 质感逐段微抖

只抖颗粒/暗角/光晕（±10%），几何仍整套统一——几何逐段变会导致接缝构图跳。
用户拉到 0 的项保持 0（随机不能把「关掉」加回来）。

## 3. 触发与回滚

- 微变速/帧预算/质感微抖都挂在「画面放大」开关下：关掉放大 → 完全走旧路径（含旧的拼接方式）。
- `fx_sig` 在开画面放大时多了 `|F1` 版本位：**旧成片会被判成需要重渲一次**（用户已确认接受）。
- 台账只加字段，不删除旧字段；`reuse` 缺失时行为与改前一致。

## 5. 还没标定的数（用真实片子标一次再调）

| 常量 | 现值 | 说明 |
|---|---|---|
| `audiofp.NEAR_SIM` | 0.60 | 整片相似度低于它不做定位；实测共用 60% 块 ≈0.62 |
| `audiofp.MIN_RATIO` | 0.10 | 段级重合占比到这条线就提示 |
| `audiofp.E_TOL` | 0.70 | 能量余弦命中线（实测同源 0.83+、异源 0.2） |
| `reuse.MAX_USE` | 3 | 同一块最多用在几套里 |
| `render.FP_SPEED` | 0.3%/0.7%/1.2% | 逐段变速振幅（soft/std/strong） |

建议评测集：同源 10 组（重编码/换容器/换 BGM/换解说/剪 10%/换分辨率/加片头/微变速）+ 异源 10 组
（同剧不同集、不同剧同题材）。标完把结果记进 `tests/去重评测.md`。

## 6. 已知边界

- 台账按项目存：换项目/换剧不共享（这是有意的，不同剧的素材不该互相压制）。
- 单集钩子模式（`mode:"hook"`）不记账，也不做微变速（`speed_of=None` 时仍会按 1.0 生成计划，但时长守恒、无观感变化）。
- BGM 混音在成片之后，不影响音轨对齐。
- 旧指纹（v1，无 stride 头）仍可整片比对；定位走 `locate_files` 不受影响。
